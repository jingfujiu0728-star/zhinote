## 首页蜂窝水滴

首页采用轴向 q/r 六边形坐标，从中心向外按环扩展。不完整外环分散布置，避免少量对象集中在一侧。绘制位置经径向投影压缩，中心水滴略大，外围逐渐缩小；最小点击直径 48dp。沿用原有笔记/待办色彩规则、标题和状态信息。

Canvas 绘制柔和莫奈色彩、玻璃渐变、细阴影及高光。首页不再运行星群、粒子、漂浮或引力模拟。坐标布局仅在对象顺序变化时计算；拖动/缩放更新绘制和测量阶段，无需每帧重组所有图标，静止时没有持续帧循环。

整片蜂窝支持边缘裁切、单指拖动与衰减惯性、双指缩放（0.8～2 倍）。点击有轻微弹性，选择时邻近水滴稍微避让，新增/删除进行 280ms 坐标补位。多指松手不触发单指惯性。绘制、实际触摸命中与无障碍目标共用投影位置。

仍使用现有选择和待办完成回调：单击打开详情，同一待办双击完成，笔记双击打开，完成/撤销/循环规则保持原样。笔记、待办独立页面及其现有水滴视图没有改造。

## 日历动态收缩

使用一个记录 LazyColumn 和共享头部偏移。NestedScrollConnection 先消耗日历收起/展开位移，再交给记录列表。月份标题、左右切换按钮、月/周/日栏、星期行和日期网格作为同一整体向上移动，并被裁切至完全不可见。日期网格没有固定到顶部。

收起后只保留 48dp 日期栏，包含选中日期、星期及记录数量。点击日期栏平滑展开，向下拖动也可以展开。用户拖动会中断点击展开动画，避免动画与手势争夺偏移。直接拖动头部同样调整这一偏移，不引入第二个纵向滚动容器。

日期、月份、月/周/日模式和列表状态保留。展开/收起不发起数据库查询；记录来自原有数据流，按原有日期规则在内存过滤。月份按钮、横向月份手势、今天按钮及日期选择均已验证。

## 性能与兼容性限制

最终实时触摸采样使用 100 个临时笔记、四次拖动和两次缩放，运行真实 Choreographer，未使用 Compose 虚拟时钟。去重后的 321 个 FrameMetrics 样本，平均耗时 **14.04ms**，P95 **21.42ms**，101 个样本超过 16.67ms；采样持续约 7.7 秒。见 [实时性能 JSON](v21-realtime-performance.json)。最初的 Compose 合成手势采样受虚拟时钟影响，仅作测试排查记录，不作为实际 FPS 结论。

此次功能验收通过，但不能据短时 Debug 帧耗时宣称持续 60fps：P95 仍超过 60Hz 的单帧预算，系统调度和 Debug 开销可能导致偶发掉帧。尚未进行 release 长时呈现帧率、耗电或热稳定性测量。没有新增服务、定时器或后台任务。

实机覆盖一台 Redmi K90；其他屏幕宽度经过几何测试，其他品牌、系统版本、横屏/超小窗口及更极端字体比例仍需额外实机验证。紧凑栏固定 48dp，过长文本会换行或省略；蜂窝标题会省略，完整标题保留在详情及无障碍语义中。

本次没有发现两个 UI 模块的未修复功能性失败。AI 接口/密钥、数据库结构、用户内容、待办规则、小部件、提醒、搜索、统计和分类业务均未修改。
