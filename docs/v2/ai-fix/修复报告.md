# 2.0.1：AI 空内容修复

日期：2026-11-15。versionName 从 2.0.0 升至 2.0.1，versionCode 从 2 升至 3；包名、签名、Room schema 和已有加密配置保持不变。修复版已覆盖安装到原手机。

## 根因与修复

原连接测试发送 `max_tokens=12`，输出预算包含思考型模型在生成正文前的推理消耗，可能只得到思考内容或额度耗尽后的空正文。旧客户端只读取 `message.content`，没有识别 `finish_reason`，统一报“AI 返回了空内容，请切换模型”。

使用手机已有的加密配置实际复现了原错误，见 [修复前真实请求](live-before.txt)。用户配置为 DeepSeek `deepseek-flash`；修复后相同配置连接与生成都成功，未要求重新填写密钥。真实响应正文、思考文本和密钥未写入日志；现有证据没有保留修复前服务端的完整响应，因此不声称已逐项确认其 finish_reason。

改动：

- 连接测试额度从 12 提升到 4096 token；生成从 4096 提升到 8192 token。
- 总超时从 45 提升到 90 秒，读取超时从 30 提升到 60 秒；保留取消、15 秒连接超时和 1 MB 响应上限。
- 抽出 `AiChatProtocol`，识别额度耗尽、思考内容但没有正文、空正文、拒绝和服务错误；不给用户显示原始服务错误或思考文本。
- 支持字符串与文本块数组正文。`null` 不会转为字符串“null”，思考文本不会当作笔记正文，截断响应不被报告为成功。
- 新增输出预算、空/思考/截断响应、正常正文与错误信息的回归验证；真实接口测试必须显式 `-e liveAi true`，默认测试不会调用用户的服务商。

主要文件：`ai/AiClient.kt`、新增 `ai/AiChatProtocol.kt`、`AiChatProtocolTest.kt`、`AiDeviceTest.kt`、新增 `AiLiveDeviceTest.kt`、版本配置及说明。完整相对 V1 清单见 [修改清单](修改文件清单.md)。
