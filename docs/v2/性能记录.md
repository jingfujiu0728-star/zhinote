# V2 星群真机短时性能

日期：2026-11-15。设备 2510DRK44C、Android 17 / API 37、HyperOS OS4.0，显示刷新率约 120Hz，构建类型 debug。原始数据：[performance.json](performance.json)。

每个场景额外插入 10/20/40/60 条临时笔记，原有可见条目 4 个，上限 60；开启漂浮、关闭减少动态和性能模式，预热约 1.5 秒，采样约 10 秒，随后清理测试条目并恢复设置。使用 Window.FrameMetrics，按 INTENDED_VSYNC_TIMESTAMP 去重，记录 TOTAL_DURATION、GPU_DURATION、PSS 和进程 CPU 时间。

去重回调频率**不是 SurfaceFlinger 实际呈现 FPS**。该设备同一 vsync 可能返回两个回调，因此原始约 240 回调/秒不能解释为 240fps。TOTAL_DURATION 包含管线阶段，不能直接按倒数换算实际 FPS；这些数据仍显示多水滴的绘制成本。

所有场景平均或 P95 超出 120Hz 的 8.33ms 帧预算，60 滴回调频率也下降。不能声称 60 滴稳定 120fps。本次是 debug 短时采样，未完成 release、Perfetto、持续拖动/连续消散和长时间热稳态测量；V1、V2 场景的原有内容与界面状态不同，不作严格同条件性能提升结论。

已有优化：缓存玻璃渐变材质、物理与绘制分离、位置变化主要触发绘制和放置、空间分桶碰撞、受控步长、后台暂停、减少动态开关。低性能模式最多 20 滴、约 30Hz 更新并减少粒子；系统中度热压力临时降级。数学稳定性通过 JVM 物理测试，不能作为设备实际帧率证明。
