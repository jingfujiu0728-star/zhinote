# AI 接口配置与使用

2.0.1 已修复连接测试额度不足导致的空内容问题，使用手机保存的 `deepseek-flash` 配置通过真实连接与笔记预览测试。见 [修复报告](ai-fix/修复报告.md)。

## 配置服务商

1. 打开 ZhiNote「我的 → AI 接口」。
2. 使用 DeepSeek 预设，或点「新增其他服务」填入服务商名称、HTTPS Base URL、API Key、模型列表和默认模型。
3. 多个模型用英文或中文逗号分隔，默认模型必须在列表中。
4. 点击「保存配置」。卡片上的模型按钮可选择模型并设为默认服务商；「编辑配置」「测试连接」「删除配置」管理该服务商。
5. 「测试当前配置」可以在保存前验证输入，测试成功表示对应模型返回了可解析的响应。

DeepSeek 预设 Base URL 为 `https://api.deepseek.com/v1`，模型预设 `deepseek-chat,deepseek-reasoner`。实际可用模型、额度和接口参数以服务商账户为准。OpenAI-compatible 服务可填写其 Base URL 和模型名称。

客户端请求 `POST <Base URL>/chat/completions`，若填写的地址已经以 `/chat/completions` 结尾则不会再附加。请求使用 Bearer 鉴权、messages、model、stream=false 和 max_tokens；不自动跟随重定向。普通服务必须使用 HTTPS，debug 的设备测试仅允许本机回环 HTTP。

## 生成和保存

1. 点击首页星光 AI 按钮，或桌面「快捷添加」中的 AI 入口。
2. 选择「笔记」「待办」或「自动识别」，输入内容。
3. 点击「生成预览」。未点击确认前，生成内容不会写入笔记或待办。
4. 核对并修改标题、正文、摘要、标签；待办还可修改优先级、截止和提醒时间。
5. 点击「确认并保存」，成功后进入水滴空间。待办沿用应用原有提醒机制。

例如输入「明天下午三点提交实验报告，提前半小时提醒我」，请求会携带当前本地时间与时区，并要求返回截止时间、提前提醒和优先级。模型结果仍须核对；客户端验证提醒不能晚于截止时间。

笔记模式可以整理「记录一下今天 PLC 调试过程中出现的故障和解决方法」。模型提示要求保留事实，缺少实际故障信息时注明待补充。应用支持正文、摘要、标签，未承诺 AI 自动生成内容始终准确。

## 错误与取消

- 请求总超时 90 秒，连接超时 15 秒，读取超时 60 秒，响应上限 1 MB。连接测试输出额度 4096 token，创建额度 8192 token；思考型模型的额度包含思考消耗。
- 401/403 提示检查 Key 与权限；429 提示频率或额度；无效 JSON、网络和证书错误给出可读提示。
- 请求期间可以点击「取消请求」，保留输入；失败保留输入或预览，便于重试或切换模型。
- AI 未配置或不可用时，普通笔记与待办的手动创建继续可用。

## 配置保护与验收范围

整个服务商配置用 Android Keystore AES/GCM 加密，保存到应用 `noBackupFilesDir`；Key 不写入源码、普通错误消息或配置对象的 `toString()`，不参与 JSON 业务备份。输入 Key 不保存到 Activity 的 Bundle。重装或更换设备后需要重新配置；不要用卸载再安装的方式升级已有业务数据。

配置页会说明内容仅在点击生成时发送给所选服务商。请在服务商账户中自行管理凭据、权限与额度。

已在手机本机 HTTP 测试服务上验证兼容请求、响应解析、预览不落库、确认保存、鉴权错误和取消；加密存储与重新读取测试也通过。2.0.1 还通过了 DeepSeek `deepseek-flash` 的真实连接、笔记预览和设置页测试，未使用生产假返回结果。其他真实服务商与模型仍需分别验证。
